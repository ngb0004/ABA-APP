Synthetic assessment score files for tests and the demo site's sample picker. Generated by
`pnpm exec tsx scripts/build-assessment-fixtures.ts` using Yoma's own plain layouts (a title, a few
labelled fields, a score table). Not a publisher's report form: no item wording or protocol text.
All scores are fictional and match the synthetic seed. Read-only (chmod 444); regenerate rather
than edit, and commit the regenerated files together (the PDF carries a creation time).

- vineland3_scores.pdf: Vineland-3 domains with percentiles and subdomain v-scales (PDF text layer)
- srs2_scores.png: SRS-2 raw and T-scores (screenshot; read with local OCR)
- ablls_r_areas.xlsx: ABLLS-R skill areas, score and possible columns, date cell on another sheet
- afls_basic_living.csv: AFLS Basic Living Skills areas written as "x of y"
- pddbi_parent.txt: PDDBI parent form T-scores; carries a fictional name and birth date so the
  PHI check can be seen working (both are flagged, never stored)
- psi4_scores.docx: PSI-4 total stress and domains as a Word table
